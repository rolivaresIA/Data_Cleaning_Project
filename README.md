# Data Cleaning and Transformation with R: E-commerce Case (Shein)

**From 21 messy category files to one clean, deduplicated product dataset (R).**

![](Images/datacleaning.png)

## Why this project

Analysts spend a large share of their time cleaning data, and unreliable data means unreliable decisions. This project takes a deliberately **dirty** e-commerce dataset and applies a documented, reproducible cleaning process: consistent names and types, treatment of missing values with explicit decisions, and removal of duplicated products.

## Data

- **Source:** Kaggle, [Dirty E-Commerce Data (80,000+ products)](https://www.kaggle.com/datasets/oleksiimartusiuk/e-commerce-data-shein/data).
- **Input:** [21 CSV files](original_databases) (one per Shein product category), consolidated into **82,105 rows x 13 variables**.
- **Output:** **71,480 unique products x 7 variables**, in [`final_database/shein_products_clean.xlsx`](final_database/shein_products_clean.xlsx).

## What the cleaning does

| Step | Detail |
|---|---|
| Combine | Read all files in a loop, add the product category from the file name, bind into one table |
| Names | Harmonise hyphens, spaces and repeated underscores into `snake_case` |
| Types | Convert `price` ("$1,299.00") and `discount` ("-25%") to numeric; understand why a naive conversion silently creates `NA`s |
| Missing values | Fill product name from an alternative field (678 -> 14 missing, then 1 unnamed product removed); drop 5 almost-empty columns (> 90% missing) and a high-cardinality one; explicit rules for the rest (no discount = 0, no colour options = 0, ...) |
| Standardise | Merge "#9 Best Seller" / "#9 Best Sellers" variants; label missing ranks as `Unknown` |
| Duplicates | 8,394 products repeat; 1,545 of them with **different prices** -> keep one row per product and the **highest price** |
| Export | Final column names and order, saved as Excel |

The full walkthrough, with the reasoning for every decision, is in the **[cleaning report](01_cleaning_report.md)** (generated by the script).

## How to reproduce

Requires R and the packages `readr`, `dplyr`, `stringr`, `tidyr`, `naniar`, `ggplot2`, `writexl`.

```r
# from the repository root
source("scripts/render_report.R")   # runs scripts/01_clean_shein_data.R, writes the report and the clean dataset
```
